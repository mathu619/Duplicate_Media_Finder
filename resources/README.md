# Resources

## Fonts

The Dark Liquid Glass theme is designed for **Inter** (https://rsms.me/inter/). To get the look in the design spec exactly:

1. Download Inter from https://rsms.me/inter/download/
2. Drop these `.ttf` files into this folder:
   - `Inter-Regular.ttf`
   - `Inter-Medium.ttf`
   - `Inter-SemiBold.ttf`

If the files are missing the app falls back to the system default sans-serif — everything still works, just slightly different typography.
